# TokenDex follows PokeTokenLBI, not PokeTokenBar releases

PokeTokenBar's maintainer has published nothing since 2.5.5, and the four players TokenDex is for all run the PokeTokenLBI fork, whose Update button keeps them on its `main`. So TokenDex reproduces the rules of PokeTokenLBI's `main`, names that app in its texts, and tells builds apart by commit, since the fork keeps reporting version 2.5.5. Going back to upstream releases would mean re-auditing every figure against them.
