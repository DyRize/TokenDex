Les coups de cœur des fans

Règles reprises de l'app : 328 lignes de base jusqu'au #649, poids = capture_rate, divisé par deux quand la ligne a déjà été graduée. Métamorph : 1 chance sur 128 sur un commun qui évolue. Shiny : 1/64, 1/48 avec le Charme Chroma. Le percentile est calculé exactement (loi de Poisson-binomiale), avec demi-poids sur l'égalité.

Les éclosions qui suivent un Pokémon relâché viennent d'un œuf acheté dont la sauvegarde ne garde pas le type : elles ne comptent que pour le shiny. L'indice de chance est la moyenne des sept percentiles, c'est un résumé ludique, pas une mesure statistique. Sprites : PokeAPI/sprites.

Coups de cœur : chaque lignée additionne les voix de ses Pokémon, sur une seule branche pour Évoli et les autres évolutions multiples, au sondage Reddit de 2019 (52 000 votants, un favori chacun, données sous licence MIT). Les 75 lignées les mieux placées sont les coups de cœur, marquées ♥ dans l'historique.
